# Daily Task Manager

## Description
A simple Python-based application that helps users manage
their daily tasks by adding, viewing,
and tracking tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple menu-driven interface

## Technologies Used
- Python 3

## Concepts Learned
- Lists
- Loops
- Conditional statements
- Functions
- User input

## Future Improvements
- Save tasks permanently in a file
- Add task priorities
- Add due dates
